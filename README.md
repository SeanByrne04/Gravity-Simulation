# Gravity-Simulation
A physics simulation using real values and equations to simulate gravity of the solar system

This simulation uses Newton's law of universal gravitation to simulate the solar system gravity.

Uses pygame to render objects.

Distance scaled down by 750 million
time scale = 1 second: 10 simulated days

The planet radius is not scaled same as distance between as the distance between bodies as the planets would not be visable
(Distance between planets and sun is too large to show both their scale and distance between)

the bodies.py file can be used to make additions to the simulation and test
